# PhishAware Academy — Phishing Awareness Training

This project fulfills CodeAlpha Cyber Security Task 2: Phishing Awareness Training. The official task asks for a presentation or online module explaining recognition of phishing emails and fake websites, social-engineering tactics, prevention best practices, real-world-style examples, and interactive quizzes. fileciteturn0file0L36-L41

## Features
- Interactive Streamlit training module
- Four educational modules
- Safe scenario examples
- Five-question quiz with explanations
- Safety checklist
- No credential collection and no deployable phishing pages

## Run
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run_checks.py
streamlit run app.py
```
